# PJ Industries Website

Premium industrial engineering website for **PJ Industries** — hydraulic equipment manufacturer in Chennai since 2011.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Barlow Condensed + Inter (`next/font/google`)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Placeholders

Clearly marked `[PLACEHOLDER]` content until confirmed:

- Product specs (H-Frame press, power packs, stackers, etc.)
- Services list copy
- Client logos and supply lines
- Team photos
- WhatsApp number, GSTIN, working hours, full addresses
- Enquiry email delivery (API logs until a mail provider is wired)

Edit `src/lib/site.ts`, `src/lib/products.ts`, `src/lib/services.ts`, and `src/lib/clients.ts`.

## Deploy

Connect the GitHub repo to Vercel and point the domain `pjindustries.in`.
